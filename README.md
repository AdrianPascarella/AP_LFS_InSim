# lfs_insim

A Python library for the [Live for Speed](https://www.lfs.net) InSim protocol (InSim, OutSim,
OutGauge).

> **Status: rewrite in progress.** This branch starts the project again from scratch; nothing is
> usable yet. The previous version lives in the `refactor/estabilizacion` branch.

Planned: `pip install lfs-insim`, `import lfs_insim`, Python 3.11+, no dependencies.
